# Style Guide (Warm Minimal)

- Background: #FAF7F1
- Text: #171717 (muted rgba(23,23,23,0.70))
- Ornament accent: rgba(213,126,0,1)
- CTA: #C64A3C

Principles:
- Typography-forward
- Dense but highly legible menu
- Minimal ornaments (one dotted rule accent)
- Two-panel desktop layout, stacked on mobile
