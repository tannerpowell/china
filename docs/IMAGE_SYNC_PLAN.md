
## Style Guidelines for Generation

All images should follow this style:
- **Angle**: Overhead (top-down) or 45-degree
- **Lighting**: Natural, soft lighting
- **Background**: Dark wooden table
- **Props**: Chopsticks, small sauce dishes, garnishes
- **Plate style**: White ceramic or traditional Chinese plates
- **Resolution**: 1024x1024 minimum
- **Format**: Generate both hero (4:3) and square (1:1) versions
